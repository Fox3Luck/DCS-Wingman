How it works

Three parts. Each one useful on its own.

Server

One Lua file on the dedicated server

Reports who is flying and answers chat commands. Every pilot on that server can use DCS Wingman with nothing installed. Fox3 hosted servers run it by default.

Service

Friends, presence, directory

Keeps your friendships and knows which server each friend is on right now. Your DCS identity is stored only as a keyed hash.

Client

In-game window with Join buttons

Next up. Friends list in the DCS menu and cockpit, one click to join their server, and an invite to pull a friend into yours.

For pilots

Type it in chat. That is the whole install.

On any server that runs DCS Wingman you get one line when you connect. From there it is chat commands. You can only friend a pilot who is on the same server as you at that moment, and they have to friend you back. That rule is what keeps spam out.

  1. Fly with someone. Same server, same session.
  2. -friend their name. They get a private line asking them to confirm.
  3. Next week, -friends. You see which server they are on and go there.
-wingman            help
-friend <name>      friend a pilot on this server right now
-friends            your friends and where they are flying
-unfriend <name>    remove a friend
-wingman off | on   hide or show your presence

> -friends
Rez: Contention Gulf (blue)
Plasma: Gray Flag Syria (red)
Birdman: offline
For server owners

Give your pilots a way back to each other.

One file in Scripts\Hooks, one config, one restart. Your server appears in the directory with its Discord invite and SRS address, so the new pilot who landed on your server tonight can actually find your community tomorrow.

  1. Register your server and receive a key.
  2. Copy DCS-Wingman-Reporter.lua into Saved Games\DCS.server\Scripts\Hooks.
  3. Fill in Config\dcs-wingman.cfg with the service address and your key.
  4. Restart and look for the WINGMAN line in dcs.log.
Install guide Source on GitHub 
-- Saved Games\DCS.server\Config\dcs-wingman.cfg
return {
  api_url         = "http://wingman-api.fox3cloud.com",
  server_key      = "wsk_................................",
  enabled         = true,
  report_interval = 60,
}

-- dcs.log after restart
INFO  WINGMAN: DCS-Wingman-Reporter 0.1.0 loaded
Privacy

Built so we cannot leak what we do not hold.

Hashed identity

Your DCS UCID is run through a keyed hash before anything is stored. The raw value is never written to the database.

Reversible presence

-wingman off hides you from friends and deletes your current location. -wingman on brings it back.

Counts, not names

The public directory shows how many pilots are on a server, never who. Friends see each other and nobody else.
